# Code of conduct

This is a research codebase with one maintainer and, we hope, a growing number of users and
contributors. Participation in issues, pull requests, discussions and reviews is governed by this
code.

## Expected

- Be respectful and assume good faith. Critique ideas, results and code, never people.
- Be **scientifically honest**:
  - report what the records support and no more;
  - state uncertainty, limitations and negative results (NO-GOs) as plainly as positive ones;
  - never relax a pre-registered criterion to make something pass;
  - credit prior work and data sources.
- Keep reviews actionable. Use the Conventional Comments labels (`issue:`, `suggestion:`,
  `question:`, …; see `CONTRIBUTING.md`).
- Respect people's time and boundaries, and other people's privacy (no doxxing, and no
  publishing private correspondence without consent).

## Not acceptable

- Harassment, intimidation, discriminatory language or imagery, and personal attacks.
- Unwelcome sexual attention or advances.
- Deliberate misrepresentation of results, data or someone else's work.
- Sustained disruption of discussion, or encouraging any of the above.

## Scope

This code applies in all project spaces: the GitHub repository and its issues, pull requests and
discussions, and any channel where someone represents the project.

## Reporting and enforcement

Report conduct concerns privately to the maintainer at **gr7x8mjy5d@privaterelay.appleid.com**,
with the subject line `[aero-research-platform conduct]`. Reports are handled confidentially.

The maintainer may:
- edit or remove comments, commits, code and issues that violate this code;
- warn;
- temporarily or permanently ban a participant.

The response is proportionate to the harm. A conflict of interest is declared, and the person
involved steps aside.
